# Direct catalog downloads

## Goal
Make the Catalog button over the homepage banner provide direct access to every available PDF catalog.

## Changes
- Replace the current placeholder message with a catalog picker.
- List every available catalog by name with a direct PDF download action.
- Keep the same catalog picker available from the matching catalog buttons elsewhere on the site.
- Ensure the list is easy to use on desktop and mobile.

## Verification
- Open the picker from the homepage header and confirm every registered catalog appears.
- Test a direct PDF link and check desktop/mobile layouts for errors.
